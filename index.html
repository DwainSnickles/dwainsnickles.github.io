03 / Capabilities

          
Where the hours go

        

        
Mostly deep desktop work: custom controls, layout and painting at the GDI level,
           plus the plumbing that moves bytes between a network, a codec and a window.

      


      

        

          

            
          

          
Desktop UI engineering

          
Ribbon frameworks, custom controls and MDI plumbing in Windows Forms, ported
             forward to .NET 10 with a designer that still works.

        


        

          

            
          

          
Design surfaces & graphics

          
An object model for shapes that can be edited, dropped onto a canvas, rotated and
             painted — GDI+ text effects, cropping, custom cursors.

        


        

          

            
          

          
Media pipelines

          
LibVLCSharp in MAUI and WinForms: MP4 and HLS playback, YouTube stream
             handoff, screen recording, downloads and conversion.

        


        

          

            
          

          
Scanning & vision

          
ZXing integrations with custom overlays and runtime torch control, built for
             real hardware — including Android 9 devices.

        


        

          

            
          

          
Update & deploy plumbing

          
Self-updaters that read a manifest, fetch a build and relaunch — plus the
             generator that writes those XML manifests correctly.

        


        

          

            
          

          
System-level fixes

          
Mark-of-the-Web unblocking, Start-menu repair, registry-level troubleshooting
             wrapped in a UI that explains what it changed.
