Profile

Desktop first,
details always.

I'm Dwain. I write C# and .NET for Windows — mostly Windows Forms, increasingly .NET MAUI — and I publish the pieces I get tired of rebuilding. The repos here are working code, not demos: each one solves a problem I hit on a real machine.

Current focus

Ribbon, .NET 10,
and a graphics workstation

The 2026 work is a fork of RibbonWinForms ported to .NET 10 with out-of-process designer support, published as Dwain.RibbonLib on NuGet. It's the control layer under GraphicsWorkshop, a work-in-progress editor where graphics get placed on a design surface and rotated in place.

See the ribbon fork

How I work

Three rules I keep

1. Ship something runnable. Every repo opens, builds, and shows the problem being solved.

2. Stay native. Custom controls, real GDI+ painting, no wrapper around a wrapper.

3. Keep the tool small. A utility that fixes one Windows annoyance should not need an installer, an account, or a cloud.

01 / Trajectory

Nine years of repos,
in order

Reconstructed from public repository history — the experiments that turned into libraries, and the libraries that turned into tools.

2017

Bifrost — .NET Core on IoT

An experiment in writing one .NET Core 2 app that targets Ubuntu and Windows with the same code. First attempt at cross-platform hardware access.

2020

ZXing scanning, with overlays

Three repos of barcode scanner work: custom overlays, runtime torch toggles, and a flash example — validated on Android 9 hardware.

2022

ControlCrop, TextEffects, SharpUpdate

The custom-control year: cropping for any control, GDI+ shadowed text baked to an image, and a self-updater that reads a manifest and relaunches.

2023

AutoUpdater XML Creator — 10 stars

The most-starred repo here. It generates the manifest XML that drives AutoUpdater.NET, because getting that file right by hand is miserable.

2025

LibVLCSharp in MAUI

MP4 and HLS playback in .NET MAUI, plus a tutorial repo walking through wiring VLC into a MAUI app on .NET 8.

2026

.NET 10 ribbon + NuGet

Office-style ribbon ported to .NET 10 with working out-of-process designer support, published as Dwain.RibbonLib — and the design surface built on it.
