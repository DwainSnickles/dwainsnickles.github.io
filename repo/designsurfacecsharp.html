Design Surface

The object model and surface control that Graphics Workshop is built on.

C#0 stars0 forks
Open on GitHub ↗← Repository index

Overview

Two projects do the real work here: GraphicObjects holds the shapes and their properties, and GraphicsSurface is the control that paints them, hit-tests them and hosts the rotation handles.

It ships as source rather than a package. There is no README, so the three sample apps — WindowsFormsApp1, WindowsFormsApp2 and WindowsFormsApp3 — are the documentation: each one drops the surface on a form so you can see what it does.

What it does

Reusable object model

GraphicObjects describes the shapes independently of any window, so the model can be reused by another host.

A surface control

GraphicsSurface owns painting, selection and manipulation, with its own rotation cursor art in the resources folder.

Three runnable samples

The sample apps are the quickest way in: open one, run it, watch the surface behave.

Source-only, deliberately

No package and no README — copy the projects you need rather than taking a dependency.
