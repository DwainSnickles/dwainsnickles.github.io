Binaries, no source.

Everything below is a compiled build: unzip a portable app and run it, or drop a DLL next to a project. Source code, issues and pull requests stay on GitHub — this page never links a source archive, and every download is served from GitHub Releases over HTTPS.

Portable app · Windows 10/11 x64

PC Medic 1.3.0

One executable with no installer, no background service and no telemetry: startup control, boot and sleep tuning, disk cleanup, installed programs, winget upgrades, Windows Update driver search, the registry and shortcut audits, and benchmark rig setup. Every destructive action goes through the Recycle Bin or a backup file.

PC-Medic-win-x64.zip · 69 MB · self-contained .NET 10 build

Download PC Medic Suite with Disk Defrag · 114 MB All releases ↗

Unzip anywhere — a USB stick is fine — and run PC Medic.exe. The suite zip puts Disk Defrag beside it, and the Maintenance page picks it up automatically.

Portable app · Windows 10/11 x64

Disk Defrag 1.0.1

Portable NTFS defragmentation with a live cluster map read from the volume bitmap. It drives the storage optimiser Windows already ships — defrag /A, /D, /O — and reports the engine's own percentage on a progress strip, so a long run is never a silent black box.

Disk-Defrag-win-x64.zip · 45 MB · self-contained .NET 10 build

Download Disk Defrag All releases ↗

Analysis is read-only; defragmentation needs an elevated window, which the app asks for when you start one.

Portable app · Windows 10/11 x64

Floating Toolbar 1.0.0

A compact bar that stays on top of everything: drop-down groups for Office, browsers and Windows tools, pinned one-click icons, drag-to-reorder on the bar and inside a group, and files dropped from Explorer become buttons. Right-click adds or removes groups and entries, and Ctrl+Alt+Space shows or hides it from any app.

DLL · .NET 10 Windows Forms

RibbonLib 1.0.5

The ribbon control layer under Graphics Workshop: Office-style tabs, groups and galleries drawn with GDI+, with out-of-process designer support so the control keeps working in the Visual Studio designer. Take the standalone assembly or the package that carries it.

What is not here

No source archives,
no bundles

Source zips, clones and pull requests live on GitHub where they can be read, built and reviewed. Nothing on this page ships a third-party installer, a bundled toolbar or a downloader of its own.

MOTW Cleaner releases an .msi rather than a portable zip, so it is left to its repository page instead of being listed as portable. Anything without a release yet is source-only.
